Objetivo:
Você deverá extrair informações de sentenças judiciais de processos criminais brasileiros, com foco em delitos relacionados a tráfico de drogas e correlatos, preenchendo os dados de um dataset estruturado com diversos campos. Cada resposta deve ser produzida para cada par processo/reu – isto é, se na sentença houver mais de um réu, gere um objeto JSON separado para cada par, mantendo o mesmo número de processo para todos, mas com as informações específicas de cada réu.

Contexto:
Você receberá a íntegra de uma sentença judicial (ou de uma ata de audiência contendo a sentença) de um processo criminal no Brasil. O documento pode conter diversas seções: o início com “Vistos” ou “SENTENÇA”, o relatório dos fatos, a fundamentação, a parte dispositiva (decisória) e demais informações, como depoimentos, declarações, referências a denúncias, fundamentos legais e menções à apreensão de drogas. O texto incluirá dados sobre o réu, o juiz, a vara, as penas e diversas flags e avaliações que indicam aspectos processuais específicos.

Instruções de Extração:
1. Extraia os dados para cada par processo/reu. Se na sentença houver mais de um réu, produza um objeto JSON separado para cada par, contendo todas as informações relevantes.
2. Se alguma informação não estiver presente ou não se aplicar, utilize o valor "None" (ou null) para esse campo.
3. Respeite os formatos indicados para cada campo, especialmente para quantidades numéricas, datas e textos jurídicos.
4. Extraia exatamente os campos descritos abaixo, sem omitir ou resumir nenhum detalhe.
5. Nas seções referentes a flags e avaliações (campos com prefixos "flag_" e "aval_"), não se limite à mera correspondência textual exata. Avalie se o texto da sentença descreve as circunstâncias correspondentes aos conceitos abaixo, mesmo que expressos de formas variadas. Utilize seu julgamento para identificar sinônimos, expressões equivalentes ou contextos que indiquem a presença da condição descrita.

Especificação para as flags:
- **flag_local_de_trafico**: Indique true se o texto sugerir que o local relacionado à ocorrência está associado ao tráfico (por exemplo, menções a áreas conhecidas como pontos de tráfico, depósitos ou locais de distribuição), mesmo que não use exatamente a expressão “Local de tráfico”.
- **flag_preso_no_momento_da_sentenca**: Indique true se houver indicações de que o réu foi encontrado ou permaneceu preso no momento em que a sentença foi proferida, mesmo que descrito com variações.
- **flag_confissao_informal**: Indique true se o texto transmitir que o réu apresentou uma confissão de forma informal, ou seja, sem formalidades legais, independentemente de usar exatamente essas palavras.
- **flag_confissao**: Após descartar menções que se referem a “Confissão informal”, indique true se houver evidências de uma confissão formal do réu.
- **flag_denuncia_anonima**: Indique true se o documento mencionar que a denúncia foi feita de forma anônima, mesmo que com termos alternativos que indiquem anonimato.
- **flag_denuncia**: Após remover as menções de denúncia anônima, indique true se houver qualquer denúncia formal ou referência a acusações no texto.
- **flag_atitude_suspeita**: Indique true se o texto sugerir que houve comportamentos ou atitudes consideradas suspeitas em relação ao réu.
- **flag_divergencias_nos_relatos_dos_policiais**: Indique true se houver evidências de que os relatos ou depoimentos dos policiais apresentaram inconsistências ou divergências.
- **flag_investigacao**: Indique true se o texto mencionar que houve investigação, como referências a diligências, inquéritos ou outros procedimentos investigativos.
- **flag_interceptacao**: Indique true se o texto fizer referência a interceptações, como escutas telefônicas ou monitoramento.
- **flag_mandado**: Indique true se houver menção à expedição ou execução de mandado.
- **flag_nacionalidade**: Indique true se o texto mencionar a nacionalidade do réu de forma relevante para o caso.
- **flag_revista_vexatoria**: Indique true se o texto mencionar que houve revista vexatória, isto é, revista pessoal ou de bagagem realizada de forma constrangedora.

Especificação para as avaliações (prefixo "aval_"):
Esses campos devem ser preenchidos com true se o trecho de avaliação do caso (geralmente um resumo ou análise dos aspectos do caso) mencionar, de forma direta ou contextualizada, os termos ou conceitos correspondentes:
- **aval_antecedentes**: true se houver referência a antecedentes criminais ou históricos prévios do réu.
- **aval_conduta**: true se o texto avaliar a conduta do réu (comportamento, ação, postura).
- **aval_personalidade**: true se houver menção à personalidade ou traços pessoais do réu que sejam relevantes para o caso.
- **aval_natureza**: true se o texto fizer avaliação sobre a natureza do delito ou das circunstâncias (por exemplo, a qualidade da ação ou o contexto do crime).
- **aval_quantidade**: true se houver avaliação relacionada à quantidade (por exemplo, volume ou número de porções de drogas).
- **aval_variedade**: true se o texto avaliar a diversidade ou variedade (por exemplo, tipos diferentes de drogas apreendidas).
- **aval_circunstancias**: true se o documento abordar as circunstâncias do caso, como contexto, ambiente ou condições específicas do delito.
- **aval_consequencias**: true se houver avaliação das consequências, sejam elas legais, sociais ou pessoais decorrentes do delito.
- **aval_culpabilidade**: true se o texto indicar uma avaliação da culpabilidade do réu, ou seja, a medida em que ele é considerado responsável pelo delito.

Campos a serem extraídos:
- **processo**: Número do processo, composto por 20 dígitos (exemplo: "00316684320178260050").
- **juiz**: Nome do juiz responsável.
- **sexo_juiz**: Gênero do juiz (por exemplo, "Masculino" ou "Feminino").
- **vara**: Vara criminal responsável (por exemplo, "Xª Vara Criminal").
- **nome**: Nome completo do réu.
- **local**: Indicação do local relacionado ao réu ou à ocorrência.
- **maconha**: Informação textual sobre a maconha apreendida; se não houver, utilize "0" ou "None".
- **maconha_g**: Quantidade de maconha apreendida em gramas (numérico).
- **cocaina**: Informação textual sobre a cocaína apreendida; se não houver, utilize "0" ou "None".
- **cocaina_g**: Quantidade de cocaína apreendida em gramas (numérico).
- **crack**: Informação textual sobre o crack apreendido; se não houver, utilize "0" ou "None".
- **crack_g**: Quantidade de crack apreendida em gramas (numérico).
- **ecstasy**: Informação textual sobre o ecstasy apreendido.
- **ecstasy_g**: Quantidade de ecstasy apreendida em gramas (numérico).
- **lsd**: Informação textual sobre o LSD apreendido.
- **lsd_g**: Quantidade de LSD apreendida em gramas (numérico).
- **outras**: Outras drogas ou informações relacionadas; se não houver, utilize "0" ou "None".
- **anabolizantes**: Indicação se houve apreensão de anabolizantes ("Sim" ou "Não").
- **anorexigenos**: Indicação se houve apreensão de anorexígenos ("Sim" ou "Não").
- **haxixe**: Indicação se houve apreensão de haxixe ("Sim" ou "Não").
- **skank**: Indicação se houve apreensão de skank ("Sim" ou "Não").
- **lanca_perfume**: Indicação se houve apreensão de lança-perfume ("Sim" ou "Não").
- **tolueno**: Indicação se houve apreensão de tolueno ("Sim" ou "Não").
- **den_drog**: Trecho referente à denúncia baseada em artigos da Lei de Drogas.
- **den_outros**: Trecho referente à denúncia por outros artigos; se não houver, utilize "None".
- **sentenca**: Resultado final da sentença.
- **res_drogas**: Resultado relacionado aos aspectos de drogas.
- **res_outros**: Resultado relacionado a outros aspectos; se não houver, utilize "None".
- **pena_base**: Tempo definido como pena base.
- **agravantes33_agrup**: Informação sobre agravantes ("Sim" ou "Não").
- **confissao**: Indicação se houve confissão do réu ("Sim" ou "Não").
- **menoridade**: Indicação se o réu é menor ("Sim" ou "Não").
- **atenuantes33_agrup**: Informação sobre atenuantes ("Sim" ou "Não").
- **adolescente**: Indicação se o réu é adolescente ("Sim" ou "Não").
- **arma_de_fogo**: Indicação se houve apreensão de arma de fogo ("Sim" ou "Não").
- **interestadual**: Indicação se o processo possui caráter interestadual ("Sim" ou "Não").
- **concurso_formal**: Indicação se há concurso formal de crimes ("Sim" ou "Não").
- **estabelecimento**: Indicação se houve apreensão em estabelecimento comercial ("Sim" ou "Não").
- **aumento33_agrup**: Informação sobre aumento de pena ("Sim" ou "Não").
- **paragrafo_4o_agrupado**: Informação agregada do parágrafo 4º.
- **pena33**: Texto referente à pena.
- **pena33_meses**: Pena convertida em meses (numérico).
- **pena_drogas**: Informação textual sobre pena relacionada a drogas; se não houver, utilize "NA" ou "None".
- **pena_outros**: Informação textual sobre pena relacionada a outros delitos; se não houver, utilize "NA" ou "None".
- **tot_pen**: Pena total em texto.
- **tot_pen_meses**: Pena total convertida em meses (numérico).
- **substituicao_da_pena**: Informação sobre eventual substituição da pena; se não houver, utilize "NA" ou "None".
- **regime_inicial**: Regime inicial da pena (valores possíveis: "Fechado", "Semi-aberto", "Aberto" ou "None").
- **flag_local_de_trafico**: Booleano (true/false) – true se a sentença indicar, de forma contextual, que o local relacionado à ocorrência está associado ao tráfico.
- **flag_preso_no_momento_da_sentenca**: Booleano (true/false) – true se houver indicação de que o réu estava preso no momento da sentença.
- **flag_confissao_informal**: Booleano (true/false) – true se o texto indicar que o réu apresentou uma confissão informal.
- **flag_confissao**: Booleano (true/false) – true se, após avaliar o contexto e desconsiderar confissão informal, houver evidências de uma confissão formal.
- **flag_denuncia_anonima**: Booleano (true/false) – true se houver indicação de que a denúncia foi realizada de forma anônima.
- **flag_denuncia**: Booleano (true/false) – true se, considerando o contexto (mesmo removendo as menções anônimas), houver menção a uma denúncia formal.
- **flag_atitude_suspeita**: Booleano (true/false) – true se o texto descrever comportamentos ou atitudes consideradas suspeitas relativas ao réu.
- **flag_divergencias_nos_relatos_dos_policiais**: Booleano (true/false) – true se o documento indicar inconsistências ou divergências nos relatos dos policiais.
- **flag_investigacao**: Booleano (true/false) – true se houver indicação de que foram realizadas investigações (como diligências ou inquéritos).
- **flag_interceptacao**: Booleano (true/false) – true se o texto mencionar interceptações, como escutas telefônicas ou monitoramento.
- **flag_mandado**: Booleano (true/false) – true se houver referência à emissão ou execução de mandado.
- **flag_nacionalidade**: Booleano (true/false) – true se a nacionalidade do réu for destacada como relevante.
- **flag_revista_vexatoria**: Booleano (true/false) – true se houver indicação de que foi realizada uma revista vexatória.
- **aval_antecedentes**: Booleano (true/false) – true se o trecho de avaliação do caso mencionar de forma contextual ou explícita a existência de antecedentes criminais ou históricos do réu.
- **aval_conduta**: Booleano (true/false) – true se houver avaliação, mesmo que com sinônimos, sobre a conduta ou comportamento do réu.
- **aval_personalidade**: Booleano (true/false) – true se o texto avaliar aspectos da personalidade ou traços pessoais relevantes do réu.
- **aval_natureza**: Booleano (true/false) – true se o documento avaliar a natureza do delito ou as circunstâncias qualitativas do caso.
- **aval_quantidade**: Booleano (true/false) – true se houver avaliação do volume ou quantidade de elementos (como drogas) envolvidos no caso.
- **aval_variedade**: Booleano (true/false) – true se houver avaliação sobre a diversidade de itens ou substâncias apreendidas.
- **aval_circunstancias**: Booleano (true/false) – true se o trecho de avaliação abordar as circunstâncias específicas em que os fatos ocorreram.
- **aval_consequencias**: Booleano (true/false) – true se o texto avaliar as consequências legais, sociais ou pessoais decorrentes dos fatos.
- **aval_culpabilidade**: Booleano (true/false) – true se o documento avaliar a culpabilidade ou o grau de responsabilidade do réu.

Formato da Resposta:
- A saída deve ser um array de objetos JSON. Cada objeto deve representar um par processo/reu contendo todos os campos listados acima.
- Se alguma informação não estiver disponível no texto, preencha com "None" (ou null) conforme apropriado.
- Mantenha os formatos exatos para cada campo:
  - Valores numéricos para quantidades (ex.: gramas, meses, idade);
  - Strings textuais para descrições, justificativas e referências legais;
  - Booleanos (true/false) para flags e avaliações.
- Responda cuidadosamente com os dados extraídos do texto, avaliando o contexto e as diversas formas de expressão dos conceitos descritos.
